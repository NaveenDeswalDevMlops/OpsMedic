# SOP — Miscellaneous (general queries, how-to, requests not fitting other queues)

## Triage checklist
1. Restate the request in one sentence and confirm with the user — misrouted tickets are common here.
2. Check whether it actually belongs to another category (Access, Hardware, Purchase...) and re-route if so.
3. Search the knowledge base for an existing how-to article before hands-on work.

## Standard resolution steps
1. How-to questions: answer from the KB article, link it, and offer a short walkthrough.
2. One-off requests: fulfil if within service-desk authority; otherwise identify the owning team and hand off with context.
3. If no KB article exists for a repeated question, draft one and submit for publication.
4. Close with the user's confirmation and correct final categorization so reporting stays clean.

## Escalation
Escalate to the Service Desk lead if ownership is unclear after one hand-off attempt.
